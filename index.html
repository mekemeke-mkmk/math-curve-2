One window

Define, tune, place. Everything happens in the Math Curve window.

  1. Define functions

    Add y = f(x), x(t), y(t), or a 3D curve, or start from a preset. Errors are explained in plain words, and an unknown name becomes a variable with one click.

  2. Tune on the graph

    Drag variable sliders with your own min and max and watch the graph update. Discontinuities such as tan(x) are split instead of joined.

  3. Place and create

    Pick a sketch line or the sketch origin, preview the curves on it in the viewport, then click Create Curves. One undo removes them all.

Features

Built for exact geometry, and fast in large sketches.

Light curves

Each curve is one smooth spline through every sample point, with no extra sketch points, so later edits stay fast.

Preview without side effects

The preview on the baseline is display-only: it never changes the sketch, the timeline, or your profiles.

Real units

Work in mm, cm, m, in, or ft. Fusion user parameters can be used in any expression by name.

Safe creation

Heavy calculations stop before they slow Fusion down. If any curve cannot be built, nothing is created and the reason is shown.

Orientation controls

From end, Flip X, and Flip Y per function, with red +x and green +y arrows on the baseline.

Your library, saved

Functions are saved automatically on your computer, and can be exported and imported as a JSON file.

Preset gallery

Start from a classic curve.

21 presets ship with the add-in. These are drawn live from the same formulas.

What's new in 26.3.0

A single window for the whole workflow.

  • Function list, editor, live graph, placement, and creation in one window.

License and privacy

Try everything for 30 days.

Trial
The 30-day trial has every feature of the paid version.
License check
Verified with Autodesk Marketplace in the background when you open the window, without blocking Fusion. A successful check is kept in memory for up to one hour and never written to disk.
Privacy
Geometry is processed on your computer. Only your Autodesk user ID and the app ID are sent, directly to Autodesk, to verify the license.
Requirements
Autodesk Fusion on Windows. An internet connection is needed for the license check.
